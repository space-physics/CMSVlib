# Craig Markwardt IDL libraries

Obtained from 
[Internet Archive](https://web.archive.org/web/20251108184138/http://cow.physics.wisc.edu/~craigm/idl/listing.html) 
as the original COW UW Madison site was removed.

The CMSVlib files are here of course as `cmsv*.pro` files.
They may be a useful reference for adapting to other languages like Python 
[scipy.io.readsav](https://docs.scipy.org/doc/scipy/reference/generated/scipy.io.readsav.html)
to which we have contributed.

We present these files as obtained, with no checks of any kind.
